# 🏥 Healthcare Data Analysis

This project analyzes healthcare patient data using **Python** to explore patient demographics, diagnoses, admission patterns, hospital stays, feedback, billing, insurance coverage, and other healthcare-related factors.

## 🔍 What I Worked On

- Data exploration and understanding
- Data cleaning and handling missing values
- Checking duplicate records
- Data type analysis
- Date and time handling
- Feature engineering
- Admission year, month and day extraction
- Discharge year, month and day extraction
- Feedback categorization
- Hospital stay categorization
- Weekend admission analysis
- Patient age analysis
- Diagnosis analysis
- Admission type analysis
- Insurance provider analysis
- Billing analysis
- Health insurance amount analysis
- Outlier detection using IQR
- Exploratory Data Analysis (EDA)
- Automated data visualization

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Key Analysis

The project explores:

- Patient distribution by diagnosis
- Patient distribution by admission type
- Patient distribution by age group
- Insurance provider analysis
- Admission patterns by month
- Feedback category analysis
- Hospital stay distribution
- Weekend vs weekday admissions
- Billing amount analysis
- Health insurance amount analysis
- Patient age distribution
- Feedback distribution
- Hospital stay analysis
- Outlier detection using histograms and box plots
- Statistical analysis using minimum, maximum, mean, sum and count

##  Feature Engineering

Several new features were created to improve the analysis, including:

- Discharge Year

- Discharge Day
- Feedback Category
- Hospital Stay Category

## 📈 Data Visualization

The project uses automated visualization techniques to analyze different categorical and numerical variables using:

- Bar charts
- Pie charts
- Line charts
- Histograms
- Box plots
- Distribution plots

##  Objective

The main objective of this project is to practice **real-world healthcare data cleaning, feature engineering, exploratory data analysis, outlier detection and visualization** using Python and extract meaningful insights from patient healthcare data.
